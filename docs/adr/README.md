# Architecture Decision Records

ADR 回答“为什么”。这里只记录会长期约束架构、存在重要取舍且无法从代码直接还原的决策。

## 约定

- 命名 `NNNN-slug.md`，四位序号；新增时取当前目录内最大编号 +1。
- 标题下标注 `状态` 与 `日期`，正文按 `## 背景`、`## 决策`、`## 结果` 组织，并说明备选方案与潜在风险。
- 已发布 ADR 的编号不再变动。决策被推翻时新增一份 ADR 记录取代关系，不修改历史内容。
- 工具用法、测试命令、依赖清单和可随实现局部调整的约定记录在 README、`AGENTS.md`、`rules/` 或代码中。
