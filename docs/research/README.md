# Research

外部资料的调研存档。存放从上游一手资料整理出的结论，供后续实现或评估时查阅，**不构成本仓库当前生效的约束**。

适合记录：

- 版本升级指南与迁移要点（如 [typescript-7-upgrade.md](./typescript-7-upgrade.md)）
- 上游设计、品牌与产品参考（如 [vercel-design.md](./vercel-design.md)）
- 外部规范摘要、选型对比与实测数据

约定：

- 每份文档在开头写明资料出处（链接或来源说明）。
- 结论一旦被采纳为工程约束或架构决策，写入 `rules/`、`docs/adr/` 或代码，不留在本目录。
- 上游变化时允许整体重写本目录内容；这里不是事实真源，取值以代码与 `docs/adr/` 为准。
