# 字体与字号

字号阶梯表达内容的阅读层级，每个级别对应一种阅读角色。

实现上使用 Tailwind 标准字号阶梯，字体族消费主题变量；不在调用处写任意字号或字体族。

## 6:3:1 排版字阶法则

字号与字重表达内容的阅读层级。视区内的文字篇幅与视觉重量遵循 [6:3:1 注意力法则](design-quality.md#631-注意力与权重法则)，避免全屏等大、多处加粗或层级断层。

| 配比层级 | Class 阶梯 | 推荐字重 | 阅读角色与场景 | 越界禁令 |
| :--- | :--- | :--- | :--- | :--- |
| **60% 基础阅读** | `text-xs`<br>`text-sm`<br>`text-base` | `font-normal`（默认） | 正文长文本、表格行数据、表单说明、辅助标注与 Badge | 严禁低于 `text-xs`（12px）；严禁给普通正文大面积叠加 `font-semibold` 或 `font-bold` |
| **30% 结构分层** | `text-lg`<br>`text-xl` | `font-medium`<br>`font-semibold` | 模块小标题、卡片标题、表单分组 Label、加强正文 | 严禁列表项每行套用 `text-lg` 标题字号；严禁卡片内部跨级使用页面级标题 |
| **10% 核心焦点** | `text-2xl`<br>`text-3xl`<br>`text-4xl` 及以上 | `font-bold` | 页面主标题、Hero 展示文案、看板核心 KPI 巨型数值（配 `tabular-nums`） | 严禁同一视区出现多个等权 `text-2xl+` 标题；严禁普通容器滥用展示性字号 |

- 需要阶梯外的字号时先扩展主题 Token，不在调用处写任意值；新增级别与相邻级别保持可感知差异与递进比例，具体取值由主题维护。
- 品牌与自定义字体通过 `next/font` 注入主题变量，组件使用 `font-sans` / `font-mono`，接入见 `apps/web/app/layout.tsx`。
- 内容装不下的取舍属构图问题，按 [构图规则](design-quality.md) 精简重组，不得通过缩小正文字号强行塞入。

## 数字字形（Tabular Numbers）

| 判据（何时适用）                                                                     | 处理                                                |
| ------------------------------------------------------------------------------------ | --------------------------------------------------- |
| 内容宽度可变，且容器尺寸或位置需保持固定（动态数值、倒计时、进度变化、固定尺寸徽章） | 使用 `tabular-nums`；容器尺寸固定时叠加 `min-w-*`   |
| 需要纵向逐位比对的数值列（表格、对账清单）                                           | 使用 `tabular-nums` 并 `text-right`，表头同步右对齐 |

- 正文叙述、长篇段落与大字号展示标题保持比例数字；数字（如 `1`）两侧留白过大会破坏阅读节奏与字距灰度。
- 不在 `body` 或全站根节点全局开启 `tabular-nums`；仅在数值组件与数据容器局部按需声明。
- 仅需数字等宽时勿滥用 `font-mono`，保留无衬线正文字体的字形曲线与风格。
