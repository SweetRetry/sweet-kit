# 尺寸稳定

状态变化必须保留用户的空间定位，避免周围内容或操作中的控件突然跳动或横向穿孔。

## 1. 尺寸守恒

- **异步容器预留最小尺寸**：异步获取数据的内容区必须预设与稳态等高的最小尺寸或固定比例，禁止加载前高度为 0。
- **媒体声明宽高比**：所有异步加载的图片、视频必须显式声明比例（`aspect-video`、`aspect-square`）或固定尺寸，禁止依赖自然尺寸撑开容器。
- **交互控件尺寸锁定**：按钮进入加载或禁用状态时锁定物理尺寸，严禁因文案替换为 Spinner 而宽度缩水。

## 2. 空值与边界防塌陷

- **文本节点高度保持**：数据为空或未返回时，外层保留最小行高（`min-h-[1lh]` / `min-h-5`）或使用占位符。
- **空列表结构化兜底**：`[]` 时呈现等体量 Empty State，严禁直接渲染空白或折叠父容器。
- **双向防御**：超长文本声明溢出控制（`truncate` / `line-clamp-*`）；缺失数据用安全导航与占位字符（`data?.name ?? "—"`）。

## 3. 异步与状态防突变

- **Skeleton**：路由级与主要内容区首次加载使用，1:1 匹配最终渲染态体量；完成后周围偏移为 0。
- **Loader**：按钮提交、局部刷新等就地反馈，放在触发控件内，不阻塞无关区域。
- **表单校验错误预留空间**：字段下方预留最小提示高度（`min-h-[20px]`）或受控展开，避免推挤导致误触。

## 4. Flex/Grid 防穿孔

可能包含文本或动态内容的 Flex/Grid 子项必须添加 `min-w-0`，解除 `min-width: auto` 的默认撑宽行为。

## 验收清单

- [ ] **尺寸恒定**：异步内容具备 `min-h-*` 或等比 Skeleton，无高度跳动。
- [ ] **媒体受控**：图片与媒体声明了宽高比或明确尺寸。
- [ ] **按钮防抖**：Loading 状态物理宽度不缩水。
- [ ] **空值防御**：缺失数据或空数组时不塌陷，有行高托底或等体量 Empty State。
- [ ] **边界安全**：Flex/Grid 动态内容项有 `min-w-0`，长文本截断生效。
