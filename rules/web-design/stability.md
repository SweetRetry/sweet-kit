# 尺寸稳定

状态变化应保留用户的空间定位，避免周围内容或正在操作的控件突然移动。

## 加载与状态切换

| 场景                     | 处理                                                 |
| ------------------------ | ---------------------------------------------------- |
| 页面或主要内容首次加载   | 骨架匹配最终布局的体量、间距和行高，预留合理最小尺寸 |
| 图片、视频等媒体         | 声明尺寸或宽高比，不等下载完成再撑开容器             |
| 按钮提交或禁用           | 保持控件宽高，文案换成 Spinner 后仍保留原有占位      |
| 局部刷新、翻页或增量加载 | 保留已有内容，就地呈现反馈，不阻塞无关区域           |
| 空结果与错误             | 明确展示状态，保留必要的内容区体量，避免容器突然折叠 |
| 表单校验提示             | 预留提示空间或受控展开，避免点击目标突然移位         |

## 数据边界

- 按数据契约处理缺失、空结果与失败，不把所有字段一律视为可空，也不通过默认值掩盖异常。
- 缺失文本仍需要维持布局时，使用行高占位或需求明确的空值标记；不伪造姓名、角色或业务数据。
- 长文本根据重要性换行、截断或局部滚动；关键内容不能只因布局限制而不可访问。
- Flex/Grid 中需要收缩的动态内容项解除最小宽度限制（如 `min-w-0`），保证溢出控制生效；固定操作区保持可用。

检查首次加载、局部更新、空结果、失败与极长文本，确认布局没有明显跳动或横向溢出；不要求所有内容状态机械地固定同一高度。
