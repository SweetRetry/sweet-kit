# 动效与交互反馈

动效服务于状态感知、空间连续性与操作确认；高频操作优先即时响应，转场保持可打断并尊重减少动态效果偏好。

## 时长与缓动阶梯

常规 UI 交互优先低于 300ms；退场通常不长于进场。

| 场景 | 建议时长 | 推荐缓动 | 越界禁令 |
| :--- | :--- | :--- | :--- |
| **按压与即时反馈** | 100–160ms | `ease-out` | 严禁 > 200ms |
| **Tooltip / 小型 Popover** | 125–200ms | `ease-out` / `cubic-bezier(0.23, 1, 0.32, 1)` | 严禁连续滑移时重复播放延迟动画 |
| **Dropdown / Select** | 150–250ms | `ease-out` / `cubic-bezier(0.23, 1, 0.32, 1)` | 严禁从视口中心无锚点展开 |
| **Dialog / Sheet** | 200–500ms（偏短） | 抽屉 `cubic-bezier(0.32, 0.72, 0, 1)` | 严禁阻塞紧急关闭 |
| **原地形态切换** | 200–300ms | `ease-in-out` | 严禁纯 `ease-in` |

- **严禁 `ease-in`**：启动极慢，产生迟钝感。
- **Spring 参数**：普通 UI 避免弹跳；`duration + bounce` 与 `stiffness + damping + mass` 不得混写。

## 物理自然度

- **缩放入场**：从 `scale(0.95)` + `opacity: 0` 起步；严禁 `scale(0)` 凭空戳出。
- **按压确认**：`active:scale-95` 配 150ms `ease-out`（过渡 `scale`，禁止 `transition-all`）。缩放仅作用于指针按压，键盘与减少动态效果分支保持原尺寸。
- **锚点感知**：Popover 和下拉菜单从触发按钮方向展开，严禁统从中心放大；居中 Dialog 保持中心锚点。
- **Tooltip 连环跳过**：同一工具栏滑移到相邻图标时，跳过延迟与动画即时切换。

## 性能防线

- **合成属性优先**：`transform` 与 `opacity`；位移不得通过 `top`、`left`、`margin` 实现。
- **禁止 `transition-all`**：显式声明具体过渡属性。
- **布局动画**：优先检查 `layout` / `layoutId`。动画不替代 [尺寸稳定](stability.md) 中的加载占位。避免逐帧更新 React 状态。

## 可打断性与可访问性

- **可打断**：元素从当前视觉状态转向最新目标，不跳回起点、不排队播放过期帧。业务状态变更不等待动画结束。
- **`prefers-reduced-motion`**：彻底移除位移、缩放与 3D 运动；可保留轻微透明度或颜色过渡。
- **触屏防粘连**：悬停动效仅在 `(hover: hover) and (pointer: fine)` 下生效。

## 验收清单

- [ ] **参数适配**：常规交互 ≤ 300ms，无 `ease-in`，Spring 参数未混用。
- [ ] **空间连续**：缩放入场从 `scale(0.95)` 起步；Popover 具备锚点感知。
- [ ] **可打断**：连续操作衔接最新状态，业务逻辑不等待动画。
- [ ] **性能安全**：显式声明受控属性，无 `transition-all`。
- [ ] **可访问**：减少动态效果下无位移与缩放；触屏隔离 `:hover`。
