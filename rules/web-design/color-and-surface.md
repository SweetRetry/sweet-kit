# 色彩与表面

色彩是信息传达系统，服务于功能、状态与注意力引导。UI 框架退位于内容，先定布局与高度语义，再取语义 Token。

## 色彩服务于状态与语义

每个由 UI 系统添加的非中性色必须承担明确职责：

- **状态**：绿色成功/正常、红色危险/错误、黄色或橙色警告、蓝色信息、灰色中性，全局一致。
- **注意力**：高显著色用于主行动点（CTA）或阻断状态；次要操作使用中性或低显著样式。
- **框架退位**：背景、卡片、侧栏与输入区优先中性色或低彩度色。内容本身已具高彩度时，UI 框架退至近无色化。

## 6:3:1 视觉配比

视区内的色彩与表面视觉重量遵循「60% 主基底 : 30% 辅助结构 : 10% 关键焦点」配比（与[构图注意力法则](design-quality.md#631-注意力与权重法则)一致）：

| 层次 | 职责 | 对应语义 Token | 越界禁令 |
| :--- | :--- | :--- | :--- |
| **60% 主基底** | 视区画布与大底，提供稳定中性的呼吸空间 | `background` / `foreground` | 严禁高饱和度色铺满底色；不得滥用装饰色 |
| **30% 辅助结构** | 容器、面板、侧栏与次级信息承载面 | `card`、`sidebar`、`muted`、`border` | 严禁多层同级表面层叠；不得使用缺乏对比的非语义色块 |
| **10% 关键焦点** | 主行动点、当前激活态、焦点高亮与破坏反馈 | `primary`、`accent`、`destructive` | 严禁多个等权高彩度焦点；严禁 `primary` 大面积用作装饰底色 |

### 场景判据

- **单向引导（结算、登录、向导）**：严格 6:3:1，10% 焦点色唯一指向首要操作。
- **生产创作（编辑器、画布、代码区）**：90%+ 中性基底，强调色仅在光标、选择态与必要反馈微量出现（<5%）。
- **信息看板（仪表盘、图表）**：颜色承担数据分类与状态编码，不受 10% 限制，但仍以中性色为 60% 基底。
- **品牌表达（营销页、活动页）**：品牌色可大面积使用，经 Token 定义；状态语义色与文字对比度不得被削弱。
- **内容沉浸（影视、相册、UGC）**：框架中性，局部主题可由内容提取，经 Token 限定范围并校验对比度。

## 高度模型与表面语义

按「布局关系 → 组件语义 Token → 当前主题表现」选择表面。高度描述视觉前后关系，Token 表达组件职责：

| 高度 | 布局语义 | Token 映射 |
| :--- | :--- | :--- |
| **E0 基底** | 最远的连续画布、应用背景 | `background` / `foreground` |
| **E1 结构面** | 侧栏、主面板等持久分区 | `sidebar` / `sidebar-foreground`；主面板按角色选 `background` 或 `card` |
| **E2 抬升面** | 从承载表面分离的内容或控件 | `card` / `card-foreground`；工具控件沿用自身变体 |
| **E3 浮层** | 临时覆盖的菜单、弹窗 | `popover` / `popover-foreground`；Dialog / Sheet 沿用基底或配套遮罩 |

- 内凹区域（编辑画布、代码区）由形态与交互表达，使用独立语义 Token；更暗不自动等于内凹，嵌套不自动代表抬升。
- `accent` 表达交互高亮，不是通用的"更高一层"；`input` 用于输入控件边界，不是内凹表面的通用 Token。
- Dialog、AlertDialog、Sheet 使用 `background`；Tooltip 使用 `foreground` 作为背景、`background` 作为文字色——它们仍是浮层，不在调用点强覆盖为 `popover`。

## 主题表现与 Token 维护

- 纯暗色体系，Token 取值对齐 shadcn Neutral；暗色 `card` 与 `popover` 略亮于 `background`，层级通过边框、阴影与遮罩表达。
- `forced-colors` 生效时使用系统颜色，不追踪明度关系。
- 色值集中在 [globals.css](../../packages/ui/src/styles/globals.css) 维护，业务组件消费语义 Token，严禁硬编码 Hex/OKLCH。

## 验收清单

- [ ] **语义合规**：非中性色具有明确状态/注意力职责。
- [ ] **6:3:1 成立**：焦点色控制在 10% 以内，未大面积滥用高彩度铺底。
- [ ] **高度自洽**：每个表面可归入 E0–E3；同一局部链上明度与层叠不翻转。
- [ ] **浮层脱离**：浮层去掉阴影后仍能通过明度差或边框识别。
- [ ] **Token 消费**：无内联硬编码色值，无跨语义乱用。
