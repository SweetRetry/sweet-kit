# 信息层级与收纳

决定页面信息的视觉权重、首要焦点以及次要内容的收纳去向。先理清信息关系，再选择组件承载。

## 1. 6:3:1 注意力法则与构图

视区注意力预算有限，按「60% 主体基底 : 30% 辅助结构 : 10% 关键决策」组织信息，防止视觉嘈杂或层级扁平：

| 维度 | 60% 主体与基底 | 30% 辅助与结构 | 10% 焦点与决策 | 越界禁令 |
| :--- | :--- | :--- | :--- | :--- |
| **内容与信息** | 业务主事实、默认流程主体 | 筛选条件、辅助上下文、属性说明 | 首要行动点（Primary CTA）、阻断状态 | 严禁平铺所有字段；严禁让用户在次要信息中寻找主操作 |
| **空间与留白** | 画布大底、段落宏观负空间 | 卡片内边距、组内网格间距 | 核心操作隔离留白、关键呼吸区 | 严禁无留白紧密挤塞；严禁卡片套卡片挤占内容空间 |

- **单一主导焦点**：每个视区只保留一个首要焦点，辅助信息通过字号、字重与对比度主动退让。
- **宽展数据优先**：宽幅数据表格拥有最高水平空间优先级，全宽展示，不为容纳装饰挤压列宽。
- **默认不用的模式**：
  - **反万物皆 Card**：普通列表靠留白、共享左对齐轴与 `space-y-*` 组织，不逐项套 Card + 阴影。
  - **反 Badge 泛滥**：普通元数据用 `text-xs text-muted-foreground`；Badge 仅用于强状态或核心分类。
  - **反等大指标卡**：主导指标单独放大，次要指标采用紧凑对比排版；权重不同就不等大。

## 2. 直接呈现 vs 渐进收纳

判定单位是当前场景下的用户任务。满足任一条件直接呈现，其余进入收纳：

- **直接呈现判据**：
  1. **影响此刻决定**：缺少会导致判断错误或阻断流程（代价、后果、禁用原因、报错）。
  2. **需要同时比较**：多个值必须并排核对。
  3. **当前任务高频主操作**：反复使用，折叠会严重拖慢主流程。
- **收纳载体由属性决定**：
  - **保留上下文 + 临时查看** → 锚定浮层（Popover、DropdownMenu）。
  - **保留上下文 + 持续使用 / 互斥** → 页面内切换（Tabs、ToggleGroup、Accordion 折叠区）。
  - **脱离上下文 + 专注完成独立任务** → 模态（Dialog、Sheet）。

## 3. 场景判据与收纳禁令

- **单向引导（注册/结算）**：严格收敛。只呈现推进必需信息，高级选项整体收纳并给默认值；Primary CTA 唯一明确。
- **表格与列表**：行内仅保留识别与判断所需的列和主操作，次要操作进行尾溢出菜单，完整详情进抽屉或详情页。
- **专业工具与设置**：常用高频项一次点击可达，危险设置单独成区直接可见，不藏进折叠区。
- **越界禁令**：
  - **不为收而收**：仅有一两个次要操作时直接呈现，不做溢出菜单；收纳后入口比原内容更难理解时不收。
  - **关键信息禁止仅悬停可见**：后果、禁用原因、报错不得只放在 Tooltip 中；触屏悬停不可达。
  - **禁止浮层嵌套浮层**：模态内不嵌套模态；二级内容改为模态内分步或锚定浮层。
  - **展开不推翻前提**：展开后出现的补充内容不得推翻用户基于收起态已做出的判断。

## 验收清单

- [ ] **焦点单一**：模糊细节后（眯眼测试），首要焦点与阅读路径清楚，视区无等权大标题/卡片混战。
- [ ] **同级自洽**：重复结构的对象具有相同语义和权重，不等大对象通过占比或排序体现了差异。
- [ ] **收纳可达**：首屏关键信息无折叠；收纳入口显式可见，无仅悬停可见的阻断性信息。
- [ ] **两态受检**：收起态与展开态均经过检查，浮层未嵌套浮层。
