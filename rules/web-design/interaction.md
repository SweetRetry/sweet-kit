# 交互反馈与动效

操作反馈明确其结果与后续动作，动效服务于状态感知、空间连续性与按压确认。

## 1. 反馈形态选择

反馈形态由**用户是否需要在原处修改输入**决定，不由消息严重程度决定：

| 场景 | 反馈形态 | 核心约定与禁令 |
| :--- | :--- | :--- |
| **字段校验、表单输入错误** | 字段旁 **inline**（配 `role="alert"`） | 需用户修改的错误**严禁仅用 toast**（toast 消失后用户失去修正入口） |
| **对话框内提交失败需修正** | 对话框内 **inline** | 仍在当前对话框内提示，不弹外部 toast |
| **操作结果无需修改输入**（保存、删除、导出） | **toast**（`toast.success` / `error`） | 同一动作只给一种反馈，不原地报错又 toast；成功严禁使用 Dialog 打断 |
| **局部按钮提交等待** | 触发按钮内 Loader | 局部等待严禁使用 `toast.loading`；仅跨页面或原上下文消失时长任务由 toast 承接 |
| **异步长任务完成** | toast 覆盖（同 `id` 承接） | `toast.loading` 获取 `id`，结束后用同一 `id` 转为 success/error 覆盖 |
| **批量操作部分失败** | `toast.warning`（带成功/失败数） | 单条提示交代整体统计，不连弹多个 toast |
| **后台连接中断与恢复** | toast 固定 `id` | 驻留提示用固定 `id`，连接恢复时 `toast.dismiss(id)` |
| **列表无数据** | 空状态占位 | “暂无数据”严禁使用 toast（空属于持续状态） |
| **页面级加载失败** | 页面级错误态 + 重试入口 | 错误态持续可见，不以 toast 替代 |

- **toast 文案极简**：toast 只承载一句话，更详细补充信息保留在原处。

## 2. 动效节奏与物理自然度

常规 UI 交互优先低于 300ms（Dialog / Sheet 按下表），退场通常不长于进场：

| 交互场景 | 建议时长 | 推荐缓动 | 禁令 |
| :--- | :--- | :--- | :--- |
| **按压与即时确认** | 100–160ms | `ease-out` | 严禁 > 200ms |
| **Tooltip / 小型 Popover** | 125–200ms | `ease-out` / `cubic-bezier(0.23, 1, 0.32, 1)` | 相邻图标滑移时跳过动画即时切换 |
| **Dropdown / Select** | 150–250ms | `ease-out` | 严禁无锚点从视口中心展开 |
| **Dialog / Sheet** | 200–500ms（偏短） | 抽屉 `cubic-bezier(0.32, 0.72, 0, 1)` | 严禁阻塞紧急关闭 |
| **原地形态切换** | 200–300ms | `ease-in-out` | 严禁纯 `ease-in` |

- **缓动起步要快**：进场用 `ease-out`，原地切换用 `ease-in-out`；`ease-in` 启动极慢，造成迟钝感，不用于 UI 动效。
- **缩放入场基准**：从 `scale(0.95)` + `opacity: 0` 起步，严禁从 `scale(0)` 凭空弹出。
- **按压物理反馈**：`active:scale-95` 配 150ms `ease-out`（显式过渡 `scale`，禁止 `transition-all`）。缩放仅作用于指针按压，键盘与减少动态效果分支保持原尺寸。按压反馈属于组件外观，由 `packages/ui` 变体或 recipe 提供，调用点不追加。
- **锚点感知**：Popover 与下拉菜单从触发控件方向展开；居中 Dialog 保持视口中心锚点。
- **Spring 参数**：普通 UI 避免弹性晃荡；`duration + bounce` 与 `stiffness + damping + mass` 不得混写。
- **布局动效**：优先使用 `layout` / `layoutId`；动画不替代 [尺寸稳定](stability.md) 中的加载占位，避免逐帧更新 React 状态。

## 3. 性能防线与可访问性

- **仅使用合成属性**：动效属性仅限 `transform` 与 `opacity`；位移禁止通过 `top`、`left`、`margin` 实现。
- **严禁 `transition-all`**：必须显式声明具体过渡属性（如 `transition-[transform,opacity]`）。
- **可打断性**：连续操作衔接最新状态，不跳回起点；业务状态逻辑不等待动画结束。
- **`prefers-reduced-motion`**：彻底移除位移与缩放动画，仅保留轻微透明度或颜色过渡。
- **触屏防粘连**：悬停动效仅在 `(hover: hover) and (pointer: fine)` 媒体查询下生效。

## 验收清单

- [ ] **形态归位**：需修正输入的错误在字段旁 inline，操作结果用 toast，无重复反馈。
- [ ] **状态归位**：空数据用空状态占位；页面级失败有持续可见的错误态与重试。
- [ ] **等待受控**：按钮提交等待在按钮内部，未滥用 `toast.loading`；长任务/连接提示通过 `id` 复用或关闭。
- [ ] **时长与缓动**：时长落在对应场景的阶梯内（常规 < 300ms），无 `ease-in`，无 `scale(0)` 起步。
- [ ] **性能安全**：显式声明受控过渡属性，无 `transition-all`。
- [ ] **可访问性**：支持减少动态效果；触屏设备隔离了 `:hover` 动效。
