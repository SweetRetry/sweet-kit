# 布局与间距

用留白、共享对齐轴与表面差异表达分组；组件外观由变体提供，调用方负责布局。

## 间距与归属

- 常规间距和内边距使用 8px 网格，如 `gap-2/4/6/8`；4px 微距用于图标、标签等紧密关联元素。
- 行高托底与必要的光学微调不受 8px 网格限制，优先选现有 Token；不为普通布局引入零散任意值。
- 组间距至少为组内间距的 2 倍；标题靠近所属内容，上方留白大于下方。标签与输入框先成组，再安排表单项间距。
- 内边距从页面到面板、列表项逐级收紧；文本控件水平内边距通常大于垂直内边距，由组件变体统一维护。

## 父容器负责间隔

- 可复用组件不自带外部 margin，兄弟间隔由父容器的 `gap-*` 或 `space-y-*` 统一控制。
- margin 用于自动推挤、负边距通栏与长文本排版流；不逐个给列表项补 `mb-*` 或 `mr-*`。

## 网格与对齐

- 页面和复杂看板使用 12 栏响应式网格：主辅可用 8/4，同级双栏可用 6/6；移动端默认单列，避免挤出不可读的窄栏。
- 同级对象才使用等宽布局；内容权重由 [构图规则](design-quality.md) 决定，网格不要求所有区块等权重。
- 图标与单行文本居中对齐，标题与辅助操作按基线对齐；可比较的数值使用 [tabular-nums](font-system.md#数字字形tabular-numbers)，数值列及表头右对齐。

## 光学微调与视错觉对齐

以视觉重心（Eye）为基准，不盲从包围盒几何中心（Math）：

| 场景                               | 识别依据                                                    | 推荐处理                                                                                  |
| ---------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 容器内不对称图形（如 Play / Star） | 实体面积分布不均（Play 图标重心偏左），几何居中在视觉上显偏 | 局部微调 1~2px（如 `translate-x-px`）；用模糊滤镜（`filter: blur()`）检查色块重心是否居中 |
| 图标与文字混排按钮                 | 图标外框自带负空间，与内边距叠加导致图标侧过显松散          | 削减图标侧 1~2px 内边距（如 `pl-3 pr-2.5`），平衡两端视觉负空间                           |
| 引用块首行开双引号                 | 引号下方留白导致首行文字相比下文视觉凹陷                    | 用 `hanging-punctuation: first`（或负缩进 `indent-[-0.42em]`）实现标点悬挂对齐            |

- 光学微调是特定图标或组件变体的专属决策，仅在局部封装（如复合按钮或图标容器），不得外溢为通用布局规则。
