# 布局与间距

用留白、共享对齐轴与表面差异表达逻辑分组；组件外观由变体提供，调用方负责布局。

## 间距与格式塔亲密性

间距体现亲密性（Proximity）。相关联的元素紧密靠拢，不相关的模块明显拉开。

- **间距网格**：常规间距和内边距遵循 8px 网格（`gap-2/4/6/8`）；4px 微距仅用于图标、角标等紧密关联元素。
- **亲密性倍率**：**组间距必须达到组内间距的 2~3 倍以上**。标题上方留白大于下方；标签与对应输入框先成组，再安排表单项间距。

## 父容器负责间隔

- 可复用组件不自带外部 margin，兄弟间距由父容器 `gap-*` 或 `space-y-*` 统一控制。
- `margin` 仅用于自动推挤（`ml-auto`）、负边距通栏及长文本排版流；严禁逐项补 `mb-*` 或 `mr-*`。

## 12 栏响应式网格

页面画布和复杂看板严禁随意使用绝对像素宽度，优先纳入 12 栏栅格（`grid grid-cols-12`）：

| 布局形态 | 列分配 | 适用场景 |
| :--- | :--- | :--- |
| **主辅非对称** | `col-span-8` + `col-span-4` | 详情页主体 + 侧栏 |
| **对称双栏** | `col-span-6` × 2 | 双栏表单、左右对比 |
| **三列看板** | `col-span-4` × 3 | 功能卡片、方案比较 |
| **四列指标** | `col-span-3` × 4 | KPI 统计卡片 |

桌面端跨多列的子项，移动端默认 `col-span-12` 垂直平铺。

## 视觉连续性与对齐

- **图文混排强制轴线对齐**：图标与文本并排时 `inline-flex items-center gap-2`；大标题伴随辅助操作时用 `items-baseline`。
- **数值列等宽右对齐**：金额、百分比、时间戳使用 `tabular-nums text-right`，表头同步右对齐。

## 格式塔闭合与无形边界

- **虚边界优于物理框**：列表项共享严格左对齐轴时，人眼自然识别同组。
- **微弱明度差优于实线**：用留白和微弱明度差建立空间秩序，取代高对比度 1px 边框。
- **分隔线克制**：先靠留白分区；成组列表允许 `divide-y divide-border/40`，不把 `<Separator />` 作为默认分区手段。

## 光学微调

以视觉重心为基准，不盲从几何中心：

| 场景 | 处理 |
| :--- | :--- |
| 不对称图形居中（Play / Star） | 微调 1~2px（`translate-x-px`） |
| 图标与文字混排按钮 | 削减图标侧 1~2px 内边距 |
| 引用块首行双引号 | `hanging-punctuation: first` 或负缩进 |

光学微调仅在局部封装，不外溢为通用规则。

## 验收清单

- [ ] **亲密性倍率**：组间距达到组内间距 2~3 倍以上。
- [ ] **组件零外边距**：复用组件根节点无外部 margin。
- [ ] **网格与响应式**：复合看板基于 12 列栅格，窄屏 `col-span-12` 退化。
- [ ] **轴线对齐**：图标与文字 `items-center`，数值列 `tabular-nums text-right`。
- [ ] **无形边界**：依靠对齐与留白分区，无滥用卡片嵌套和高对比度边框。
