# 层叠

层叠表达元素在视觉上的前后关系：越接近用户当前注意焦点的元素越靠前。

## 何时分层

- 普通布局依靠 DOM 顺序；只有需要重叠时才设置 z-index。
- 头像堆叠、焦点环、Tab 指示器等局部重叠，由父容器用 `isolate` 隔离，避免子元素参与外部排序。

## 层级阶梯

- 业务层只用以下阶梯，不写任意 z-index，不超过 `z-50`；第三方组件内部层级由其自身管理。

| 层级             | 用途                   |
| ---------------- | ---------------------- |
| `-z-10`          | 背景装饰               |
| `z-auto` / `z-0` | 普通内容               |
| `z-10`           | 隔离容器内的局部重叠   |
| `z-20`           | 局部吸顶与拖拽把手     |
| `z-30`           | 固定导航               |
| `z-40`           | 需要独立分层的遮罩     |
| `z-50`           | 弹窗、菜单与提示等浮层 |
