# 构图与信息层级

设计由当前任务、内容关系与交互状态产生，先决定信息如何组织，再选择组件承载。

## 构图原则

1. **一个主导焦点**：每个视区只保留一个首要焦点，辅助信息通过字号、字重与对比度主动退让。
2. **关系先于组件**：先用顺序、比例、位置、共享刻度、连接或分组表达内容关系，再决定是否需要卡片、表格或图表。只有语义、结构和操作真正同级的对象才使用重复或等宽布局；权重不同的对象用排序、分组、占比或密度表达差异。
3. **层级先于装饰**：优先用排版、对齐、密度、节奏和负空间建立层级。表面、边框、颜色、图标与动效只在增加语义或可供性时出现。分组用单层表面承载，禁止卡片套卡片。
4. **真实编码**：同级数据共享统一基准轴与比例刻度，条柱长度与面积严格线性对应真实数值。数值优先就地标注，维度过多才使用独立图例。
5. **数据宽展优先**：宽幅数据表格拥有最高水平空间优先级，横向滚动或全宽展示，不为容纳旁侧装饰而挤压列宽。
6. **文案直陈**：文案直接陈述业务数据与操作结论，不向用户叙述页面设计背景、排版理由或过往尝试。
7. **内容决定密度**：信息不足时如实保留空缺，不用面板、指标或特效填充；信息密集时先重组取舍，不通过缩小正文或压缩控件硬塞。

## 6:3:1 注意力与权重法则

视区的注意力预算是有限的。通过「60% 主体基底 : 30% 辅助结构 : 10% 关键焦点」的配比组织内容、排版、空间与色彩，防止所有元素等权重争夺注意（视觉嘈杂）或缺乏落脚点（层级扁平）：

| 维度 | 60% 主体与基底 | 30% 辅助与结构 | 10% 焦点与决策 | 越界禁令 |
| :--- | :--- | :--- | :--- | :--- |
| **内容与信息** | 业务主事实、默认流程数据与阅读主体 | 筛选条件、辅助上下文、属性说明与次要操作 | 首要行动点（Primary CTA）、关键结论或阻断状态 | 严禁平铺所有字段；严禁让用户在次要信息与等权卡片中寻找主操作 |
| **排版与字阶** | `text-sm` / `text-base` 正文、段落与数据行 | `text-lg` / `text-xl` 分节标题、卡片标题、表单 Label | `text-2xl`+ 页面主标题、核心 KPI 巨型指标（tabular） | 严禁全屏均等大字或多处加粗；严禁同一视区出现多个等权大标题 |
| **空间与留白** | 页面画布留白、段落间距与宏观负空间 | 卡片与控件内边距、组内网格间距（8px 网格） | 核心操作隔离留白、关键区域的呼吸区 | 严禁无留白紧密挤塞；严禁使用嵌套容器或装饰性边框挤占内容空间 |
| **色彩与表面** | `background` 画布、中性底色（详见[色彩规则](color-and-surface.md#631-视觉配比60-30-10)） | `card`、`sidebar`、`muted` 结构面 | `primary` 引导色、`destructive` 关键反馈 | 严禁多色均分注意力；严禁大面积铺用高彩度强调色 |

### 场景判据

- **单向引导流程（注册、结算、发布）**：严格收敛。内容只保留推进主线所必需的事实，10% 焦点仅保留一个推进主按钮（Primary CTA）。
- **信息看板与监控（Dashboard、分析图表）**：60% 面积留给数据图表与明细行，30% 用于维度筛选与卡片容器，10% 聚焦核心 KPI 大指标与异常报警。
- **专业工具与编辑器（画布、IDE、文档编写）**：90%+ 空间与认知预算让渡给用户创作内容，工具栏与面板退入 30% 辅助层，强调色仅在交互反馈与选区极微量出现（<5%）。

## 默认不用的模式

下列模式不能作为默认构图；只有当它直接表达当前任务关系、并且移除后会损害理解或操作时才使用：

| 模式 | 替代方案 |
| :--- | :--- |
| **万物皆 Card** | 普通列表用留白、共享左对齐轴与 `space-y-*` 组织，不逐项套 Card + 阴影 |
| **Badge 泛滥** | 普通元数据用 `text-xs text-muted-foreground`；Badge 只标强状态（`destructive`、`warning`）或核心分类 |
| **等大指标卡矩阵** | 主导指标单独放大，次要指标用紧凑对比排版；权重不同就不等大 |
| **装饰性图标块 / 插画** | 图标只在有操作识别或可供性价值时出现；空状态说明是语义信息，不算装饰填充 |
| **氛围渲染** | 避免无意义的渐变文字、光晕、网格纹理、斑点与彩色图标底色 |

## 验收清单

1. **眯眼测试**：模糊细节后，首要焦点、分组和阅读路径仍然清楚，页面不是等权重区块的无序堆栈。
2. **移植测试**：主要组织方式在只替换文案后不能直接套用于无关业务；若能直接套用，说明构图由通用模板主导而非内容驱动。
3. **同级测试**：每组重复结构中的对象具有相同语义、结构和操作；不等价对象已通过排序、分组、占比或密度体现差异。
4. **移除测试**：逐项移除卡片、边框、背景、图标、颜色和动效；不损失含义或可供性的元素一律不得恢复。
5. **响应式测试**：窄屏通过合理重排保持层级与操作，不依赖截断关键内容或缩小可读字号来维持桌面构图。
