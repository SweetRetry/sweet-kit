# 构图与信息层级

设计由当前任务、内容关系与交互状态产生，先决定信息如何组织，再选择组件。

## 构图原则

- 每个视区有明确的首要焦点，辅助信息降低视觉重量。
- 只有语义、结构和操作同级的对象才使用等权重的重复布局；其他情况用顺序、分组、占比与密度表达差异。
- 优先用排版、对齐和留白建立层级；卡片、边框、图标和动效只有在增加含义或帮助识别操作时才保留。分组用单层表面，避免卡片套卡片。
- 内容不足时如实保留空缺，不虚构指标或用装饰填充；信息密集时重组取舍，不缩小正文与控件硬塞。
- 文案直接表达业务事实与操作，不向用户解释页面设计背景。

## 6:3:1 注意力与权重法则

视区的注意力预算是有限的。通过「60% 主体基底 : 30% 辅助结构 : 10% 关键焦点」的配比组织内容、排版、空间与色彩，防止所有元素等权重争夺注意（视觉嘈杂）或缺乏落脚点（层级扁平）。

| 维度 | 60% 主体与基底 | 30% 辅助与结构 | 10% 焦点与决策 | 越界禁令 |
| :--- | :--- | :--- | :--- | :--- |
| **内容与信息** | 业务主事实、默认流程数据与阅读主体 | 筛选条件、辅助上下文、属性说明与次要操作 | 首要行动点（Primary CTA）、关键结论或阻断状态 | 严禁平铺所有字段；严禁让用户在次要信息与等权卡片中寻找主操作 |
| **排版与字阶** | `text-sm` / `text-base` 正文、段落与数据行 | `text-lg` / `text-xl` 分节标题、卡片标题、表单 Label | `text-2xl`+ 页面主标题、核心 KPI 巨型指标（tabular） | 严禁全屏均等大字或多处加粗；严禁同一视区出现多个等权大标题 |
| **空间与留白** | 页面画布留白、段落间距与宏观负空间 | 卡片与控件内边距、组内网格间距（8px 网格） | 核心操作隔离留白、关键区域的呼吸区 | 严禁无留白紧密挤塞；严禁使用嵌套容器或装饰性边框挤占内容空间 |
| **色彩与表面** | `background` 画布、中性底色（详见[色彩规则](color-and-surface.md#631-视觉配比60-30-10)） | `card`、`sidebar`、`muted` 结构面 | `primary` 引导色、`destructive` 关键反馈 | 严禁多色均分注意力；严禁大面积铺用高彩度强调色 |

### 场景判据

- **单向引导流程（注册、结算、发布）**：严格收敛。内容只保留推进主线所必需的事实，10% 焦点仅保留一个推进主按钮（Primary CTA）。
- **信息看板与监控（Dashboard、分析图表）**：60% 面积留给数据图表与明细行，30% 用于维度筛选与卡片容器，10% 聚焦核心 KPI 大指标与异常报警。
- **专业工具与编辑器（画布、IDE、文档编写）**：90%+ 空间与认知预算让渡给用户创作内容，工具栏与面板退入 30% 辅助层，强调色仅在交互反馈与选区极微量出现（<5%）。

## 常见选择

| 场景             | 优先选择                                                 |
| ---------------- | -------------------------------------------------------- |
| 普通列表与元数据 | 留白、对齐与文本，不逐项套 Card 或 Badge                 |
| 权重不同的指标   | 突出主指标，次要指标紧凑排列，不默认等大卡片矩阵         |
| 数据比较         | 共享基准与比例刻度，长度或面积对应真实数值，数值就近标注 |
| 宽幅表格         | 保留必要列宽，全宽展示或横向滚动，不为装饰挤压数据       |
| 窄屏             | 重排保留层级与操作，不截断关键信息维持桌面构图           |

品牌或实验性表达须服务已确定的艺术方向，并保持可读性、响应式行为与可访问性。

## 判断是否成立

- 隐去细节后，首要焦点、分组与阅读路径仍清楚。
- 构图能解释当前内容之间的关系，而不只是换文案即可套用的模板。
- 移除某个装饰后若不损失含义或操作识别，就不需要保留它。
